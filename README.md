# 🎉 Date Proposal & Multi-Timezone Clock

Bienvenue dans ce projet contenant deux pages web interactives !

## 📋 Pages Disponibles

### 1️⃣ **Une Proposition Spéciale** ✨
Une page originale pour faire une proposition de rendez-vous avec un bouton "Non" qui s'échappe !

**Programme :**
- ⛵ Sortie en mer avec super yacht
- 🏊 Exploration aquatique avec combinaison
- 🍽️ Déjeuner restaurant trois étoiles
- 🚶 Promenade digestive

👉 **[Accédez à la proposition ici](https://raw.githack.com/27ywv9vfpz-technologie/date-proposal/main/index.html)** 💕

---

### 2️⃣ **Horloge Multi-Fuseaux Horaires** 🌍
Une horloge numérique élégante affichant l'heure dans différents fuseaux horaires avec affichage analogique optionnel.

**Fonctionnalités :**
- 🕐 Affichage numérique en temps réel
- 🌍 Support de multiples fuseaux horaires
- ⏰ Bascule format 12h/24h
- 🔄 Affichage analogique optionnel
- 📅 Date et décalage UTC

👉 **[Accédez à l'horloge ici](https://raw.githack.com/27ywv9vfpz-technologie/date-proposal/main/clock.html)** ⏰
